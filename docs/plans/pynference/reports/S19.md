## Note per le sezioni successive

- **Gate attention folded**: nell'layer attention non esiste tensore `attn_gate`;
  `attn_q.weight` è [5120, 12288] = q (24×256=6144) + gate (6144). Il gate si
  ricava dalle seconde 6144 colonne. `attn_gate.weight` [5120, 6144] esiste solo
  nei layer DeltaNet (gate della norma con gate in uscita).
- Attention senza bias: niente `attn_*.bias`. Output proj `attn_output` [6144, 5120].
  Convenzione forme GGUF: [in, out] (ffn_down [17408, 5120]).
- **Forme layer DeltaNet (blk.0)**: `attn_qkv` [5120, 10240] = q 16×128 +
  k 16×128 + v 48×128; `ssm_conv1d` [4, 10240] F32 (canali = q+k+v);
  `attn_gate` [5120, 6144]; `ssm_a` [48], `ssm_dt.bias` [48];
  `ssm_alpha`/`ssm_beta` [5120, 48]; `ssm_norm` [128] (norma per testa sullo
  stato 128); `ssm_out` [6144, 5120]. Niente bias sulla conv.
- MTP (da ignorare, D4): `blk.64` = 11 tensori attention +
  `blk.64.nextn.{eh_proj [10240,5120] Q8_0, enorm, hnorm, shared_head_norm [5120] F32}`.
- Token speciali qwen35: 33, con tipi ggml 3/4 (la convenzione in
  `pynference/tokenizer.py` li tratta come CONTROL/USER_DEFINED/UNKNOWN).
